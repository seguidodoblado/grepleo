# Soporte / Support

## 🇪🇸 Español

## Documentación

Empieza por la [wiki](https://github.com/seguidodoblado/grepleo/wiki): [instalación](https://github.com/seguidodoblado/grepleo/wiki/es-01-4-instalacion-configuracion), [guía de uso](https://github.com/seguidodoblado/grepleo/wiki/es-01-5-guia-uso) y [solución de problemas](https://github.com/seguidodoblado/grepleo/wiki/es-01-7-solucion-problemas).

## Pedir ayuda

Si la wiki no resuelve tu duda, abre una incidencia en [GitHub Issues](https://github.com/seguidodoblado/grepleo/issues) incluyendo:

- la versión (diálogo **Acerca de**);
- tu distribución y versión (por ejemplo, Ubuntu 24.04, Linux Mint 22);
- los pasos para reproducir el problema.

No pegues tu token de Apify en la incidencia. Si el problema es con una fuente, indica el mensaje de error que muestra la aplicación y qué fuente era.

## 🇺🇸 English

## Documentation

Start with the [wiki](https://github.com/seguidodoblado/grepleo/wiki): [installation](https://github.com/seguidodoblado/grepleo/wiki/en-01-4-installation-and-setup), [usage guide](https://github.com/seguidodoblado/grepleo/wiki/en-01-5-usage-guide) and [troubleshooting](https://github.com/seguidodoblado/grepleo/wiki/en-01-7-troubleshooting).

## Getting help

If the wiki does not answer your question, open an issue on [GitHub Issues](https://github.com/seguidodoblado/grepleo/issues) including:

- the version (**About** dialog);
- your distribution and version (for example, Ubuntu 24.04, Linux Mint 22);
- the steps to reproduce the problem.

Do not paste your Apify token in the issue. If the problem is with a source, state the error message the application shows and which source it was.
