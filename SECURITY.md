# Política de seguridad

## Versiones con soporte

Solo la última *Release* publicada recibe correcciones de seguridad.

## Cómo informar de una vulnerabilidad

Abre una incidencia en [GitHub Issues](https://github.com/seguidodoblado/grepleo/issues) describiendo el problema sin incluir datos sensibles como tu token de Apify.

No hay programa de recompensas: este es un proyecto personal mantenido en el tiempo libre.
